# NBA Slider Stats

## Description

NBA Slider Stats is a comprehensive project that provides various statistical analyses and visualizations for NBA teams and players. The project includes features like per game stats, total stats, head-to-head comparisons, and clutch stats for both players and teams. The objective is to offer a user-friendly interface to explore and compare NBA statistics interactively.

## Features

- **Per Game Stats:** Analyze player and team performance on a per-game basis.
- **Total Stats:** View cumulative statistics for players and teams.
- **Head-to-Head Comparison:** Compare stats between two players or teams.
- **Clutch Stats:** Examine performance during crucial moments of the game.
- **Playoff Stats:** Focus on player performance during the playoffs.
- **Interactive Sliders:** Use sliders to filter and explore data interactively.

## Installation

To run this project locally, follow these steps:

1. Clone the repository:

    ```bash
    git clone <[(https://github.com/jjzyy/NBASliderStats)]>
    ```

2. Navigate to the project directory:

    ```bash
    cd NBA-Slider-Stats
    ```

3. Install the required dependencies:

    ```bash
    pip install -r requirements.txt
    ```
